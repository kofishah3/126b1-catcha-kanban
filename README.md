# Catcha Kanban Board

## Lab Exercise 1: Dynamic UI, DOM API, LocalStorage

### Goal

Build an Offline Kanban Board using DOM APIs and LocalStorage

### Required Functionalities

Users should be able to:

1. See three columns: To do / Doing / Done (5pts)
2. See the tasks in each column (5pts)
3. Create tasks and assign them to specific columns (5pts)
4. Move tasks between columns (5pts)
5. Delete tasks (5pts)
6. Update tasks (5pts)
7. Refresh the page and still see all tasks (10pts)
8. Do all functionalities using keyboard only (10pts)
9. Do all functionalities in mobile view also (10pts)

### Restrictions

1. Use only HTML, CSS, and JavaScript
2. No frontend libraries or frameworks
3. Use DOM APIs only (createElement, appendChild, removeChild, etc.)
4. Do not hard-code tasks in HTML
5. Do not use SessionStorage
6. Do not use any database — LocalStorage is the only storage

### Getting Started

1. Open `index.html` in your browser
2. Start implementing the required functionalities
